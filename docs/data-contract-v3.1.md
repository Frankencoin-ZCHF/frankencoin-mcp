# Data contract v3.1 — audit corrections

These are candidate code changes, not a claim that production is deployed or that optional providers are healthy. REST `ok` / MCP `isError` describe the invocation. Inspect result `status`, `sources`, or Dune `queries` for data availability. `checkedAt` is a local assessment time (possibly cached); `asOf:null` means no provider freshness guarantee.

- **I01/I05 savings:** pending proposals come from `/savings/leadrate/info.open`, not historical `proposed`. A missing open set produces an unknown/null pending count. `ratePpm` / `proposedRatePpm` preserve raw source rates. **Corrected numerical contract:** `rateBps` / `proposedRateBps` are now conventional basis points: 35000 PPM = 350 BPS = 3.5%. Clients that previously consumed the mislabelled raw fields must migrate to `*Ppm` or stop dividing the BPS value by 10000. Percent fields are unchanged. Snapshot thresholds use PPM.
- **I06/I07 governance:** pending/approved selectors are implemented; all merges open proposals with approved history before applying the output limit. Denied/active minter predicates run in Ponder before the limit. `mintersPageInfo` is additive. Ponder BigInt predicates use string literals. Existing minters and rateProposals arrays remain arrays.
- **I02/I03/I04 market:** optional CoinGecko/RPC errors and empty results have source health; partial provider datasets are marked. ZCHF USD falls back to the public price feed. Price rows expose freshness with a 24-hour stale threshold; epoch/future timestamps, missing sources and nonpositive/invalid quotes are not executable prices and become null. Old but valid quotes remain labelled stale. Position/challenge collateral quotes share this policy and expose enrichment availability. ZCHF issuer is null with the attributed no-identifiable-issuer explanation; the Association is separately identified as steward.
- **I08 Dune:** each query exposes status and safe error classification. All-null failures have `status:unavailable`, not a generic slight-delay claim. Successful queries survive failures of other queries. Missing credentials are distinct from upstream failure; this change neither provisions credentials nor repairs Dune queries/access. FCS holders remain explicitly unsupported.
- **I09/I14 analytics:** the current AnalyticDailyLog schema no longer supplies total supply, minted totals, savings/borrow rates, projected/annual earnings or trade fees. Supported daily equity/savings/FPS/realized earnings/inflow/outflow remain. Legacy output fields for removed data remain null, with `unavailableFields`; never synthesize supply from minting or equity. `rate_history.days` is a rolling window, applied in the indexed query before `limit`. The time_series embedded rateHistory remains a separate last-100-change overlay, not filtered by daily-series days. Historical monetary values remain CHF, not current-FX USD.
- **I10 content:** the fixed public GitHub Contents route falls back to the same main-branch raw file without credentials. News retains independent successful sections; failed sections are null with source status. Missing docs return unavailable status and official links, not invented content. Existing curated FCS material remains explicitly separate. Production network/quota causes require a separate operator diagnosis.
- **I11 risk:** failures are isolated by provider. Useful Xerberus ratings survive failed Pharos. Empty score payloads are unavailable; incomplete ratings are partial. Provider timestamp absence is explicit. Ratings remain third-party assessments, not guarantees or DAO ratings.
- **I12 transport:** MCP registers the full strict schema, including empty objects. Unknown properties are rejected consistently with REST. Existing read-only GraphQL, input, rate-limit, session and error-sanitisation controls remain.
- **I13 positions:** `returned` is page size, `totalMatching` is null for detail when unknown. Legacy `total` remains a deprecated page-size alias in detail with `totalScope:returned_page`; list totals are labelled source_open_population. `availableForMintingNominal` aliases the indexed allowance, while `executableMintingCapacity:null` disclaims unperformed collateral/expiry/cooldown/closed/denied eligibility checks.
- **I15 merch:** store, product and variant currency comes from the public Shopify `/meta.json` shop currency. Failure means explicit null/unavailable, never assumed USD. No cart/checkout operation is performed.

FCS remains the holder-facing wrapper/governance token, FPS the underlying Equity token. No on-chain writes, transaction or webhook features, authentication/allowlist broadening, credential changes, deployment or merge are included.

## Verification

Deterministic regressions use public response-body fixtures and explicitly synthetic failure cases; raw private logs, session headers and credentials are excluded. Run `npm ci --ignore-scripts && npm test` on Node 20–22. There is no project lint or build script; source syntax checks and `git diff --check` supplement tests. Paid/credentialed providers require separately authorised operational verification; graceful degradation is not proof of restored service.
